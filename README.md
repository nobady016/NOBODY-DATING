# NOBODY • Anonymous & Premium Connections

An exclusive social networking and chat platform designed for anonymous interactions, rich media sharing, live calls, and match discovery.

🌐 **Live Demo:** [https://ais-pre-ykwuegkrzagh5dqus6amek-353208909594.asia-east1.run.app](https://ais-pre-ykwuegkrzagh5dqus6amek-353208909594.asia-east1.run.app)

---

## 🌟 Key Features

- 🔒 **Anonymous & Secure Messaging**: End-to-end user privacy with custom handles.
- ⚡ **Match & Discover**: Dynamic profile exploration, preferences filtering, and interactive swipe/connect mechanics.
- 💬 **Real-time Chat**: Text, multimedia sharing, audio clips, and reaction support.
- 📹 **Audio/Video Calls**: High-quality calling interfaces.
- 👑 **Admin Dashboard**: Analytics, user management, and configuration controls.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Tailwind CSS, Motion, Lucide Icons
- **Backend & Database**: Express, Firebase Firestore & Authentication
- **Build Tool**: Vite
